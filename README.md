# BARBACK — Interactive Bartending Simulation & Learning Platform

> **Jazz Bar × Graphic Novel × Vintage Cocktail Culture × Modern Interactive Game**

Barback is an interactive bartending simulation and gamified learning platform that combines the fast-paced engagement of culinary simulators with authentic mixology education.
